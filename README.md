# Jogo da Forca

Um projeto simples desenvolvido em Java, executado diretamente
no terminal, ideal para praticar lógica de programação, estruturas
de repetição, condicionais, manipulação de strings e coleções.

## Sobre o projeto

O Jogo da Forca sorteia uma palavra aleatória a partir de uma lista
interna e permite que o jogador tente adivinhar letra por letra.
A cada erro, parte do boneco da forca é desenhado até que o jogador
acerte a palavra ou perca todas as tentativas.

Este projeto dfoi criado com o objetivo de treinar:

- Estruturas básicas da linguagem Java
- Programação orientada a objetos
- Arrays e coleções (`char[]`, `HashSet`)
- Manipulação de strings

## Como executar

1. Tenha instalado em sua máquina o Java 23.
2. Execute o programa: 
````
java Main
````
